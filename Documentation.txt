\# 1. Core Structural Change



\## ❌ No Single Page App



\## ✅ Multi-Route Application (React Router)



Each major system view is its own route:



```text

/

/desktop

/terminal

/explorer/\*

/admin/\*

/section/:slug

```



This improves:



\* Performance isolation

\* Cleaner animation control

\* Easier feature scaling

\* Better SEO (for public sections)

\# 3. Smart Boot Animation Logic



\## Requirement



\### First visit within 1 hour:



Show full Ubuntu boot animation.



\### Reload within 1 hour:



Show subtle "resume session" animation.



---



\## Browser Storage Strategy



Use:



```js

localStorage.setItem("lastBootTime", timestamp)

```



Logic:



```js

const lastBoot = localStorage.getItem("lastBootTime");

const now = Date.now();

const oneHour = 60 \* 60 \* 1000;



if (!lastBoot || now - lastBoot > oneHour) {

&nbsp; showFullBootAnimation();

&nbsp; localStorage.setItem("lastBootTime", now);

} else {

&nbsp; showResumeAnimation();

}

```



---



\# 4. Animation Behavior Design



\## 4.1 First Visit (Cold Boot)



Full Ubuntu-style boot:



\* System logs (from Firestore)

\* Loading modules

\* Fade to desktop

\* Dock icons animate in

\* Wallpaper blur dissolve



Duration: 3–5 seconds



---



\## 4.2 Reload Within 1 Hour (Warm Boot)



Instead of boot:



\* Screen briefly fades to aubergine background

\* Ubuntu logo pulse

\* Quick blur → restore previous session



Duration: 800ms–1.2s



Feels like waking from suspend.



---

\# 7. Redux State Persistence Strategy



Use:



\* Redux Toolkit

\* redux-persist



Persist:



```js

{

&nbsp; theme,

&nbsp; openWindows,

&nbsp; currentPath,

&nbsp; terminalHistory

}

```



Do NOT persist:



```js

{

&nbsp; isBooting,

&nbsp; animationState

}

```
